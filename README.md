# 🐾 UniVet

O **UniVet** é uma plataforma de gestão veterinária desenvolvida como projeto de Trabalho de Conclusão de Curso (TCC) em Engenharia de Software.

O sistema tem como objetivo centralizar e facilitar a gestão de clínicas, consultórios e profissionais veterinários, oferecendo ferramentas para o gerenciamento de **tutores, animais, consultas, agenda, prontuários e vacinação**.

A plataforma é centrada no animal, permitindo que os profissionais tenham acesso de forma organizada às principais informações e ao histórico de cada paciente.

## 🚀 Funcionalidades do MVP

* Landing Page
* Login e Cadastro
* Dashboard
* Gerenciamento de Tutores
* Gerenciamento de Animais
* Agenda e Consultas
* Prontuário Veterinário
* Controle de Vacinação

## 🔜 Próximas funcionalidades

* Notificações
* Internação e Gerenciamento de Leitos

## 🔮 Funcionalidades futuras

* Integração com Inteligência Artificial
* Aplicativo Mobile
* Integração com WhatsApp
* Portal do Tutor
* Suporte para múltiplas unidades
* Recursos avançados para hospitais veterinários

O **UniVet** busca oferecer uma solução moderna, simples e acessível para auxiliar profissionais veterinários na organização e gestão de suas atividades.
